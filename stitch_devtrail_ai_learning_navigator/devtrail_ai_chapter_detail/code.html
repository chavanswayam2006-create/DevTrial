Module 3.2: Asynchronous Microtasks vs Macrotasks

Interactive Console
Single-threaded JavaScript prioritizes the Microtask Queue (Promises, MutationObserver) over the Macrotask Queue (setTimeout, setInterval, I/O). Observe the evaluation sequence below:
event-loop-demo.js
V8 v12.4.254
// 1. Synchronous execution enters Call Stack immediately
console.log('1: Start');
// 2. Macrotask delegated to Web APIs, queued for next tick
setTimeout(() => {
console.log('2: Macrotask (setTimeout)');
}, 0);
// 3. Microtask queue drains before macrotasks
Promise.resolve().then(() => {
console.log('3: Microtask (Promise.then)');
});
// 4. Final synchronous statement in current script frame
console.log('4: End');
Console Output Stream Execution time: 3.82ms
> 1: Start
> 4: End
> 3: Microtask (Promise.then)
> 2: Macrotask (setTimeout)
